Источники: **[сх]** — схема реплики 240.2 romychs v1.0.3 (`upstream/ocean-240.2/KiCAD`), прочитана по нетлисту (`tools/netq.py`) и **проверена схемной моделью** (`src/sim/schem`: нетлист → Verilog, модели ТТЛ / БИС, Icarus) — такие факты помечены **[sim]**; **[МПСС]** — статьи Тилинина 1986/2, 1986/4, 1987/3; **[MAME]**, **[JS]** (эмулятор Морозова), **[AC]** (FPGA AndrejChoo) — только для сверки.

## Память [сх]

ОЗУ — 16 × КР565РУ7 (256K × 1) = 2 банка по 256 КБ = **512 КБ**: банк выбирает A8 (~CAS1 / ~CAS2), видео читает оба банка за раз (16-битное слово).

Порт C1 (ВВ55 DD17, порт B):

| Бит | Цепь | Что |
|---|---|---|
| B0 | 32K | A15 ОЗУ = A15 \| B0: старшие 32 К страницы во всём пространстве |
| B1–B3 | A16–A18 | страница 64 К (8 страниц = 512 КБ) |
| B4 | ~ENROM | 0 — ПЗУ в C000–FFFF; 1 — там ОЗУ |
| B5 | REST | 1 — ПЗУ0 во всём пространстве (после сброса порты ВВ55 — входы, подтяжки → 1) |
| B6, B7 | ROMA13, ROMA14 | банк 8 К внутри ПЗУ 27256 (A14 — через перемычки S1 / S3) |

- ~CS_ROM0 (DD1, E000) = (E000–FFFF & ~ENROM) \| REST; ~CS_ROM1 (DD2, C000) = C000–DFFF & ~ENROM; ~OE = ~MEMR. В ПЗУ 8 К адреса A0–A12 — при REST образ повторяется.
- Цикл ЦП к ОЗУ (CP-EX) = SYNC & не ПЗУ & не ввод-вывод (биты состояния D4 OUT, D6 INP). Запись в область включённого ПЗУ в ОЗУ не идёт.
- Адрес ОЗУ ЦП: строка {A17, A2, A1, A0, A13–A9}, столбец {A18, A16, A14, A7–A3, A15 \| B0}.
- **Видео-ЗУ** [сх]: A15 = A14 = 1 (C000–FFFF), A13–A9 = столбец SC5–SC1, A7–A0 = строка SK8–SK1, A16 = **VSU** (E1 B7: страница 0 или 1 по 64 К), A17 = A18 = 0. Слово = байт A8 = 0 и байт A8 = 1.

После сброса Монитор / тест: `JMP E003` (ПЗУ0 везде), `OUT C3, 80h` — выходы DD17 = 0: ПЗУ1 в C000, ПЗУ0 в E000, ОЗУ страница 0 **[sim: PB = 00]**.

## Порты [сх]

Дешифратор DD11 по A15–A13 (для портов это A7–A5), без учёта память / ввод-вывод: `~CSC0` и `~CSE0` выбирают и ВВ55, и ПЗУ (ПЗУ — по ~MEMR).

| Порты | Микросхема | Что |
|---|---|---|
| 00–03 | ВВ55 DD79 | пользовательский (X5) |
| 20–3F | разъём X4 / DD80 | **контроллер дисковода** (в реплике разъём «FDC», RDSYS = READY ЦП); в 240 по МПСС — пользовательская ВВ55 |
| 40–43 | ВВ55 DD78 | PA — клавиатура (X2); PB (ввод): B0 GC, B1 GK, B2 лента (TAPE4 — компаратор), B3 есть сигнал ленты (TAPE5), B4 ACK принтера, B5–B7 JST1–3 (X2); PC: C0–C3, C5–C7 — X2, C4 KBD_ACK |
| 60–63 | ВИ53 DD70 | 0 → RST4; 1 → ~TXC / ~RXC ВВ51; 2: CLK = TIM_IN, GATE = TIM_EN, OUT → TIM_OUT (XT1) |
| 80–81 | ВН59 DD75 | IR0 RST_0 (X2), IR1 RST_1 (X2, клавиатура), IR2 RxRDY ВВ51, IR3 принтер (ACK ⊕ BUSY), IR4 таймер 0, IR5 питание, IR6 / IR7 XT1; входы X2 / XT1 через инверторы DD71 |
| A0–A1 | ВВ51 DD72 | C/~D = A0; TxRDY не подключён (опрос статуса), RxRDY → IR2 |
| C0–C3 | ВВ55 DD17 | PA — VS (вертикальный сдвиг), PB — память (выше), PC — HS (горизонтальный сдвиг) |
| E0–E3 | ВВ55 DD67 | PA — принтер; PB: B0–B2 COL (палитра), B3–B5 FL (фон), B6 C/~M (цвет), B7 VSU (страница видео); PC: C0–C2 ЦАП ленты (R31 5K1 / R32 10K / R33 20K: веса 4 / 2 / 1, дальше дифференцирующая RC — линия повторяет изменения уровня), C3 Bell, C4 строб принтера, C5–C7 USER1–3 |

ВН59: тест / Монитор пишут ICW1 = 12h, ICW2 = 00h (векторы `CALL 0000 + 4n`), маска FFh, EOI, OCW3 = 0Ah (чтение IRR). Монитор 240/7 опрашивает клавиатуру по IRR бит 1 (`IN 80`), а не по прерыванию.

## Видео [сх]

- Сдвиг по вертикали: SK = K + VS (DD18 / DD19). По горизонтали: SC = {C5 \| GC, C4–C1} + HS[7:3] (DD20; SC5 = HS5 ⊕ (C5 \| GC) ⊕ перенос через DD22.1 / DD23); HS[2:0] (SB1–SB3) — компаратор DD43 сравнивает фазу DD42 {768K, 1.5M, 3M, 6M} с {SB3, SB2, SB1, 1} и этим моментом тактирует ССИ (DD64.1) и задержанное гашение (DD64.2): синхро и гашение сдвигаются на SB цветных точек относительно данных. HS = 07h — без сдвига [МПСС].
- Данные: слово ОЗУ → DD38–DD41 (КП13, выбор C/~M) по спаду S1 → сдвиговые DD34–DD37 (ИР16, загрузка ~VR, сдвиг по спаду 6M) → RG1 (DD35), RG2 (DD37). MD — байт с A8 = 0 (банк ~CAS1), DB — A8 = 1. Монохром: RG1 = MD0 2 4 6 DB0 2 4 6, RG2 = MD1 3 5 7 DB1 3 5 7, точки чередуются по 6M → на экране слева направо биты 0–7 байта A8 = 0, затем 0–7 байта A8 = 1. Цвет: RG1 = MD0–7, RG2 = DB0–7, точка i = {DB[i], MD[i]} **[sim: тестовое ПЗУ `mkrom_vidtest.py`]**.
- Конвейер **[sim]**: слово столбца n читается, пока счётчик слов = n, и показывается, пока он = n + 1; окно BLNK при SB = 7 открывается на 15-й точке слова 0 и закрывается на 15-й точке слова 32. Поэтому первая точка окна — последняя точка слова, прочитанного при счётчике 47: столбец 31 + HS (SC5 = HS5 ⊕ (C5 \| GC) ⊕ перенос, DD22.1 / DD23), а последняя точка столбца 31 закрыта. При SB < 7 этого столбца видно больше: так сдвиг по точкам «заворачивает» картинку. Это свойство схемы, у ядра так же.
- ПЗУ палитры DD66 (РТ4, открытый коллектор): A0 = 6M, A1 = RG1, A2 = RG2, A3–A5 = COL1–3, A6 = C/~M, A7 = BLNK (1 = видимая часть: NOR(GK, задержанное GC)). D0 = BLANC (показать фон), D1 → **G**, D2 → **B**, D3 → **R**.
- Выход X1: R = D3 \| FL1 & BLANC, G = D1 \| FL3 & BLANC, B = D2 \| FL2 & BLANC (эмиттерные повторители, фон через VD1–VD3).
- По ПЗУ `Ocean_240_RT4_VC.bin` (= рис. 6 МПСС): монохром — при 6M = 0 точка RG1, при 6M = 1 — RG2 (12 МГц); палитра 0: точка — белый, иначе фон. Цвет: индекс {RG2, RG1}, палитра 0: 0 — фон, 1 — G, 2 — B, 3 — R. **Таблица 2 МПСС даёт для палитры 0 «чёрный, красный, зелёный, синий» — не совпадает**; [JS] декодирует так же, как схема. Берём схему + ПЗУ.

## Электронный диск CP/M

Обе CP/M (REL.5, REL.7): диск A: — страница 1 ОЗУ (64 КБ), DPB SPT 16, BSH 3 (блок 1 КБ), DSM 63, DRM 31, AL0 80h, OFF 0; записи по 128 байт через Монитор (E021). Холодный старт форматирует каталог (E5), если слово 0006 не равно BDOS: BC06 у REL.5, BA06 у REL.7 (D642: `LHLD 0006; LXI D,-BDOS; DAD D`).
