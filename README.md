# Ocean-240 core for Karabas Go / Mini / Mini G

A core of the Soviet personal computer Ocean-240 / Ocean-240.2 («Океан-240», 1985–1986) for the Karabas Go board family (Xilinx Spartan-6 XC6SLX25).

Status: planning. See `docs/PLAN.md` (in Russian).

Licence: GPL v3 (`LICENSE`). Written from the schematic of the Ocean-240.2 replica by Roman Boykov ([romychs/ocean-240.2](https://github.com/romychs/ocean-240.2), BSD-3) and the articles of D. A. Tilinin in «Микропроцессорные средства и системы» 1986–1987.
